# Storm Sentence Lab

**EL Publishing · Grades 9–12 · ELP Standard 10**

A single-file platform that teaches English learners to stop writing run-on sentences — and gives teachers the coaching tools to run it.

## What's inside

| Tab | For | What it does |
|---|---|---|
| **Coach Lessons** | Students, whole class | Seven lessons taught step by step on a chalkboard by Coach Rivera: what a run-on is, finding the seam, the four fixes, and choosing a fix. Autoplay or step through; captions in English and Spanish |
| **Run-On Clinic** | Students | Spot the Seam (tap where the 2nd idea begins) · Fix It (period / comma + FANBOYS / semicolon / subordinator, with relationship checks) · Paragraph Checker (paste your own writing; flags likely run-ons and comma splices) · One-breath test |
| **Grammar Lab** | Students | Six stations with a coach lesson + 8 one-chance questions each: Subjects & Verbs · Independent vs. Dependent · Comma + FANBOYS · Subordinators · Semicolons & Transitions · Sentence Triage |
| **Games** | Students | Sentence Surgery (60-second seam hunt) · Combine-It Studio (join two sentences; splice and fused detection) |
| **Daily Dose** | Students | 3 run-ons a day for 180 school days, keyed to the Week 1 start date; streaks |
| **Exit Ticket** | Students → teacher | Copy-to-clipboard ticket, or opens the class Jotform/Google Form link if the teacher sets one |
| **My Progress** | Students | Six badges, stats, printable certificate |
| **Coach Lab** | Teachers / instructional coaches | Six 10-minute mini-lesson scripts (Hook → Model → Guided → Check) with timer, Level 3 → Level 4 model pairs with "what a rater sees," class error log, settings, printable anchor chart |

## Student-controlled Spanish toggle
The **EN / ES** switch in the top bar changes every direction, button, coach bubble and feedback message. English practice sentences stay in English (the target). The choice is saved on the student's device.

## Four lanes
Newcomer · Emerging · Progressing · Challenge — 40 run-ons total (10 per lane), plus lane-matched Combine-It items. Lane choice is saved on the device.

## Audio
Coach voices use the device's built-in speech (no files, no account). On phones the first tap unlocks audio.

## Deploy
Upload `index.html` to the repo root and turn on GitHub Pages (Settings → Pages → main, root). No build step, no dependencies beyond Google Fonts.

## Teacher setup (optional)
Coach Lab → Settings: set the **Week 1 start date** (drives Daily Dose) and paste an **exit-ticket form link**. Settings save on that device only.
